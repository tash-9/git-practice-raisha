# Project Description

## 1. Introduction

Git & GitHub Practice is a beginner-level project created as part of my practical assignment. It combines basic Python programming with version control practice using Git and GitHub.

## 2. Project Overview

This project is a simple Python program that displays my name, prints the current date, and performs basic mathematical calculations using predefined numbers.

## 3. Main Features

- Displays my name: Tasfia Islam Raisha.
- Prints the current date automatically.
- Performs addition using the `add()` function.
- Performs subtraction using the `subtract()` function.
- Performs multiplication using the `multiply()` function.
- Performs division using the `divide()` function.

## 4. Program Structure

The project is organized into separate files to make the code easier to understand and maintain.

- **main.py:** Displays my name and the current date, calls the calculator functions, and prints their results.
- **utils.py:** Contains reusable functions for addition, subtraction, multiplication, and division.

## 5. Tools Used

- Python for writing and running the program.
- Visual Studio Code for editing the code.
- Git for tracking changes and managing commits.
- GitHub for hosting the project repository.

## 6. Learning Outcomes

Through this project, I have practiced writing Python functions, organizing source files, initializing a Git repository, making commits, creating branches, merging changes, and preparing a project for GitHub.

## 7. Conclusion

This project helped me understand the fundamentals of Python programming and version control. It also provided practical experience in organizing a small software project and tracking its development using Git and GitHub.
